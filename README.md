# My_DSA

# **DSA Programs in C**  

### **About This Repository**  
This repository contains **Data Structures and Algorithms (DSA)** programs implemented in **C**, covering essential sorting algorithms, searching techniques, and data structures.  

### **What's Inside?**  
- **Sorting Algorithms:**  
  - **Bubble Sort** (with Time Complexity)  
  - **Merge Sort** (with Time Complexity)  
  - **Insertion Sort** (with Time Complexity)  
  - **Selection Sort** (with Time Complexity)  
  - **Quick Sort** (with Time Complexity)  

- **Searching Algorithms:**  
  - **Linear Search**  
  - **Binary Search**  

- **Data Structures:**  
  - **Stack (Using Arrays & Structures)**  
  - **Queue (Linear & Circular - Using Arrays & Structures)**  

### **Usage**  
1. Clone the repository:  
   ```bash
   git clone https://github.com/Ayan0106/My_DSA.git
   ```  
2. Navigate to the desired folder:  
   ```bash
   cd My_DSA
   ```  
3. Compile and run the C programs:  
   ```bash
   gcc program.c -o program
   ./program
   ```
